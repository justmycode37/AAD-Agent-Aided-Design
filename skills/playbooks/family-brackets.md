# Brackets

Unmeasured candidate guidance. Capture mounting surfaces, fastener type and pattern, envelope, load direction, load cases, material, and process. Mark guessed values as assumptions.

Keep the load path and mounting interfaces legible. Check screw-head and tool access, hole-to-edge room, mating-face orientation, and any bend or print direction. Add ribs or gussets only when the user accepts the geometry and the load path supports them; do not claim stiffness without analysis.

Review orthographic renders and sections for blocked holes, missed support faces, and interface dimensions. A hole count does not prove access or fit. Current AIAD has no persistent named feature helper; a simple current script can build a plate with BuildPart and subtract cylinders as in the core workflow.
