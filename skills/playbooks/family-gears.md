# Gears

Unmeasured candidate guidance. Before drawing teeth, get gear type, tooth counts, module or diametral pitch, pressure angle, center distance, face width, bore/key interface, material, load, speed, and backlash or fit target.

For a standard, unshifted external involute spur pair, nominal center distance is a = m(z1 + z2) / 2, where m is module and z1/z2 are tooth counts. This relation is scoped to that gear pair; profile shift, backlash, tolerances, and other gear types change the design. Do not approximate functional teeth by eye.

No AAD gear generator or standard gear catalog is present in this tree. The current standard-parts adapter lists selected fasteners, bearings, and an external thread, but no gears. Use a supplier's matching geometry or build the exact specified gear form, then check meshing with the real center distance and intended clearance. A render is not a contact, strength, noise, or lifetime analysis.

Source: [Boston Gear engineering information, spur-gear nomenclature](https://www.bostongear.com/-/media/Project/Altramotion/shared/files/Literature/brand/boston-gear/catalogs/p-1930-bg.pdf?rev=3d4fcbba1ef047e992cc9fe8a758e65a).
