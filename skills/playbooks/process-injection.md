# Injection molding

Unmeasured candidate guidance. Ask for resin, texture, pull direction, parting strategy, gate/ejection constraints, and target process.

Prefer consistent wall sections where function permits. Review ribs, bosses, internal corners, draft relative to the intended pull direction, undercuts, shutoffs, slides, and ejection. Keep material and texture in view; no single draft or wall value fits every resin or mold.

AAD heuristic screen: injection samples planar side-face normals against pull_direction. The default pull is +Z and the default minimum draft assumption is 1 degree. Curved faces, reverse draft, undercuts, shutoffs, slides, parting line, flow, ejection, shrinkage, and opposite mold halves are not established.

A pass only describes sampled planar faces under that assumed pull direction. It is not proof of moldability, filling, ejection, or part quality. Use supplier DFM or a mold review for production decisions.

Source: [Protolabs, plastic injection-molding design guidelines](https://www.protolabs.com/services/injection-molding/plastic-injection-molding/design-guidelines/).
