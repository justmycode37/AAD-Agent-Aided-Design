Workflow: call aad_new with explicit units and a spec, build model.py, inspect returned checks and failures, render views or sections, compare with the original request, then show and export the reviewed revision. Keep assumptions separate from requirements.

The current model API re-exports build123d and adds params(). Use BuildPart or assign a build123d Shape to result. Planned AAD part(), feature(), semantic selectors, and named assembly helpers are not implemented here; ordinary scripts record one main feature. Project units do not rescale coordinates. The current M0 hard gate is incomplete and withholds verified status. A valid shape, passed checks, or a complete spec does not prove the spec captured the user's whole intent.

Process results are finite heuristic screens. Read their assumptions and skips; do not call them manufacturing proof. Current spec evidence includes B-rep bounds and solid count, recognized cylindrical holes, project-contained STEP clearance, and one-point classification. min_wall and symmetry can disprove a requirement, but do not certify it from passing samples or volume alone. mass_g estimates only exact sourced material IDs using a fully dense B-rep assumption. Search aad_library for guidance, exact material definitions, or part records; construction requires the optional parts dependency. Query, measurement, 2D and interference may lack providers.
