# aiad

The `aiad` command provides the CLI, local daemon, and MCP adapter for [AIAD](../../README.md).

## Runtime packages

The `aiad` wheel declares these default runtime requirements:

- `aiad-engine==0.1.0`
- `aiad-drafting==0.1.0`
- `aiad-render[vtk]==0.0.1`; its `vtk` extra pins `vtk==9.7.1`

The workspace source mappings keep repository resolution tied to these local packages instead of similarly named registry packages. Built wheel metadata uses normal versioned distribution requirements. A registry install such as `uv tool install aiad` also requires these component distributions to be available on the configured index; this change does not publish them. `aiad_quality` is not in the current workspace and is not added as a dependency.

## Installed-wheel smoke

Run the local build and isolated install check with:

```bash
uv run --no-project --python 3.12 --script .github/scripts/packaging_smoke.py
```

The helper builds all four workspace wheels, passes the component wheels directly to `uv tool install`, and verifies `direct_url.json` provenance and site-packages imports. It uses temporary tool, home, AIAD, and client-config directories and suppresses browser launch. It prints and writes a schema-versioned JSON result to `<work-dir>/packaging-result.json` (or the path supplied with `--result`). The runtime disk measure covers `UV_TOOL_DIR` and `UV_TOOL_BIN_DIR`; it excludes the uv package cache, Python interpreter, and `AIAD_HOME` data.

### Measurement on macOS arm64

Measured 2026-11-04 on macOS 25.6.0, CPython 3.12.10. The uv package cache was empty for the fresh-install timing; the host page cache was not flushed or controlled, so this is not a clean-machine benchmark. The full doctor run used a provisioned uv cache.

| Measurement | Result | Target or scope |
|---|---:|---|
| Fresh empty-uv-cache install | 320.606 s | <=180 s; missed |
| Provisioned-cache offline install | 3.770 s | Cached result, not a fresh download |
| Runtime after install | 1,207,504,896 bytes (1.208 GB; 1.125 GiB) | Tool and bin directories |
| Runtime after validation | 1,253,093,376 bytes (1.253 GB; 1.167 GiB) | Includes generated bytecode; <=1,000,000,000 bytes missed |
| Latest prewarm | 96.453 s; completed | VTK first import 53.563 s, second 0.762 s |
| Earlier prewarm runs | 120.012–120.017 s; timed out | VTK first import timed out after about 65–70 s |
| Standalone VTK import after earlier timeouts | 35.402–47.149 s | `vtk==9.7.1` |
| Installed `aiad doctor --json` | 12.855 s; required checks passed | Real draft part, scene integrity, render, and STL export |
| Installed viewer HTML | 12,996 bytes | Packaged stub viewer |

The 320.606 s install command completed, but that earlier run stopped at its first MCP handshake before the doctor flow; use it as install timing only. Across isolated tool installs, the first MCP handshake did not return within 1.000 s (the probe stopped at 1.002 s). Traced retries returned in 0.258–0.320 s and imported none of the CAD kernel modules; the latest doctor handshake returned in 0.268 s. A no-tracer probe after clearing bytecode caches in an already provisioned tool returned in 0.590 s, with the host file cache warm. The strict first-start target is therefore still open on this host; the faster retries do not replace the cold-start result.

The doctor warns that the viewer is a stub. The draft build also reports `scene_generation_failed` while retaining the valid BREP; scene integrity, render, and export each pass afterward. Package imports, wheel provenance, and `aiad version` were verified from the installed tool. `aiad_quality` is absent and was not installed or verified.

The smoke workflow covers `macos-latest` (asserted arm64) and `ubuntu-latest` (asserted x86_64, with `libosmesa6`). This local measurement covers macOS arm64 only. It does not establish Linux results or release readiness.

## Release blockers

The measured runtime exceeds the 1 GB target, the fresh-cache install exceeds the 3-minute target, and the cold first MCP handshake missed the 1-second target in isolated runs. Prewarm completion varied: two earlier runs timed out, while the latest completed in 96.453 s without a controlled host file cache. Worker sandboxing and independent validation issue [#31](https://github.com/justmycode37/AIAD-AI-Aided-Design-/issues/31) remains a separate blocker. Keep the VTK renderer requirement intact; these misses are recorded for release planning and do not make the package release-ready.
